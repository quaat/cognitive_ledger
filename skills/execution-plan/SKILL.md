# Maintain executable plans

Start with goal, scope/non-goals, invariants, assumptions, ordered checkbox work, status, decisions, discoveries, risks, gates, evidence, deferred work, and completion criteria. Update discoveries and evidence during work. Put tangents in tech debt instead of silently expanding scope. A checkbox closes only after its verification passes. Move a plan to `completed/` only after all applicable evidence exists and create one next active plan.
