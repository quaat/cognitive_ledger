# Assess release readiness

Coordinate, do not duplicate: tests/static analysis, dependency/license audit, security, migrations, protocol compatibility, Docker images, documentation, and benchmark evidence. Read the specialist quality docs and current plan. Produce blocking defects, accepted risks, unavailable evidence, and follow-ups. Fluree is test-only. Bootstrap has no release claim until PostgreSQL CAS, auth/resource limits, container evidence, and compatibility policy are addressed.
