# Original background material (non-normative)

These documents are the historical inputs from which the Cognitive Ledger specification
was derived. They are kept for provenance only and are **not** authoritative: where they
differ from the current specification, the current documents win. The authoritative chain
is `product_development_plan.md` → `docs/product-specs/cognitive-ledger.md` →
`docs/decisions/` → the active plan in `docs/exec-plans/active/`.

- [fluree-feasibility-discussion.md](fluree-feasibility-discussion.md) — the initial
  feasibility discussion of extracting a content-addressed change DAG for Sculpin without
  reproducing Fluree as a database (formerly root `plan.md`; root `background.md` was a
  byte-identical duplicate and was not kept).
- [ledger-architecture-draft-0.1.md](ledger-architecture-draft-0.1.md) — the draft 0.1
  technical architecture and implementation specification (formerly root `ledger.md`),
  superseded by the product specification and ADR-0001…ADR-0014.
